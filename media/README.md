# Research preview sources

These silent looping previews use the corresponding public project demonstrations, resized to 560 pixels wide and encoded as MP4 for lightweight homepage playback. Most are excerpts of up to eight seconds; OpenWAM instead retains the complete task at 3× speed, with a two-second hold on the completed result. Full demonstrations remain linked from each project entry.

- `openwam-tower.mp4`: https://huggingface.co/datasets/OpenWAM/assets/resolve/main/rollouts/dx-tower_id.mp4 (complete OpenWAM dexterous toy-tower stacking task at 3× speed)
- `resmerge.mp4`: https://resmerge.github.io/static/videos/clips/pinch-cube-success.mp4 (ResMerge Pinch-Cube success demonstration)
- `dexflywheel.mp4`: https://dexflywheel.github.io/static/videos/real_robot_h264.mp4 (DexFlyWheel real-robot demonstrations)
- `psi-r25.mp4`: https://cypypccpy.github.io/scaling-pair-data.github.io/assets/videos/pair-comparison/strong-pair.mp4 (Psi-R2.5 strong human-robot paired data)
- `petaldex.mp4`: https://petaldex.github.io/stage-3.mp4 (PetalDex human-robot turn-taking co-creation)

The existing `images/psi-human-skill.gif` is retained for From Human Skill to Robotic Mastery.
